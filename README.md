# bleeARM

experimental ARM operating system project for the Lenovo TB-8505F.

## goals

- linux-based ARM userspace
- tablet-oriented bootable image
- qemu development/testing where practical
- hardware support for the TB-8505F
- eventually a custom bleeARM userspace

## build

Run `./build.sh` on an Arch Linux or Debian/Ubuntu-like build host.

The first image is a development root filesystem, not a production tablet image.

## target

Lenovo TB-8505F / Tab M8 (2nd Gen).
